# SafeLink System
## 작업자와 관리자, 사람과 환경을 '안전하게 연결'하는 시스템

**제4회 창의혁신 공모전 최종 작품**  
**Ohmazing Y (옴메이징 어드미턴스)**

---

## 🎯 프로젝트 개요

SafeLink System은 **위험한 산업 현장과 극한의 날씨에서 일하는 작업자의 안전을 혁신적으로 강화**하기 위한 통합형 웨어러블 기반 안전 관리 시스템입니다.

### 🏆 핵심 가치
- **실시간 생체 모니터링**: 심박수, 체온, 환경 데이터 동시 측정
- **3단계 위험 경고**: 고용노동부 기준에 따른 체계적 안전 관리
- **즉시 알림 시스템**: 음성, 진동, 앱 푸시를 통한 다중 알림
- **관리자 대시보드**: 다수 작업자 상태 실시간 모니터링

## 🔧 하드웨어 구성

### 📱 SafeLink Band (웨어러블 밴드)
**손목 착용형 생체 센서 장치**

| 구성 요소 | 모델명 | 기능 | 통신 방식 |
|-----------|--------|------|-----------|
| **메인 MCU** | ESP32-C3 SuperMini | BLE 통신, 센서 제어 | BLE 5.0, WiFi |
| **심박센서** | SEN0203 | 심박수 측정 (BPM) | ADC (GPIO4) |
| **체온센서** | MCP9808 | 피부 온도 측정 | I2C (0x18) |
| **온습도센서** | AHT20 | 환경 온습도 측정 | I2C (0x38) |
| **배터리** | 400mAh Li-Po | 전원 공급 | - |
| **충전모듈** | TP4056 | 배터리 충전 관리 | - |

**주요 특징:**
- ✅ **실시간 생체 모니터링**: 심박수, 체온, 환경 데이터 동시 측정
- ✅ **BLE 광고 전송**: 20ms 간격으로 센서 데이터 전송
- ✅ **WiFi UDP 통신**: 서버로 데이터 백업 전송
- ✅ **저전력 설계**: 1주일 연속 사용 가능

### 🏭 SafeLink Hub (작업복 허브)
**작업복 부착형 환경 센서 및 알림 장치**

| 구성 요소 | 모델명 | 기능 | 통신 방식 |
|-----------|--------|------|-----------|
| **메인 MCU** | XIAO-ESP32-C3 | BLE 서버, 센서 제어 | BLE 5.0, WiFi |
| **온습도센서** | AM2320 | 외부 온습도 측정 | I2C |
| **소음센서** | THC-AS01 | 소음 레벨 측정 (dB) | I2S |
| **음성모듈** | DRF0299 | 경고 음성 재생 | UART |
| **스피커** | FIT0502 | 음성 출력 | - |
| **진동모터** | 316040004 | 진동 알림 | GPIO |
| **전원스위치** | SPDT 슬라이드 | 전원 제어 | - |

**주요 특징:**
- ✅ **환경 모니터링**: 소음, 온습도, WBGT 측정
- ✅ **BLE 스캔**: 밴드로부터 생체 데이터 수신
- ✅ **3단계 경고**: 음성, 진동, 앱 푸시 알림
- ✅ **GATT 서버**: 모바일 앱과 데이터 교환

## 하드웨어 설계 요구사항

### 전원 관리
1. **저전력 설계**
   - SafeLink Band: 딥슬립 모드로 1주일 사용
   - SafeLink Hub: 스탠바이 모드로 48시간 사용
   - 배터리 잔량 모니터링 및 충전 관리

2. **전원 안정화**
   - 3.3V 레귤레이터 사용
   - 배터리 보호 회로 (과충전, 과방전 방지)
   - 전원 상태 LED 표시

### 통신 설계
1. **BLE 통신**
   - BLE 5.0 프로토콜 사용
   - 센서 데이터 실시간 전송
   - 연결 상태 모니터링

2. **Wi-Fi 통신**
   - 데이터 백업 및 동기화
   - 펌웨어 업데이트 지원

### 센서 인터페이스
1. **I²C 센서들**
   - MAX30102 (심박센서)
   - 1782 (체온센서)
   - SEN0572 (온습도센서)
   - I²C 주소 충돌 방지

2. **I2S 센서**
   - HTC-AS01 (마이크) - 소음 레벨 측정(신호처리 RMS 계산)
   - 적절한 샘플링 레이트 설정

### 출력 장치 제어
1. **음성 출력**
   - DFR0299 모듈을 통한 음성 메시지 재생
   - FIT0502 스피커로 경고음 출력
   - 볼륨 제어 기능

2. **진동 알림**
   - 3166040004 진동모터 제어
   - 패턴별 진동 신호 (경고/위험/치명적)

### PCB 설계 고려사항
1. **크기 및 형태**
   - SafeLink Band: 밴드 형태로 착용 가능한 크기
   - SafeLink Hub: 작업복에 부착 가능한 크기
   - 방수/방진 처리

2. **신호 무결성**
   - 고주파 노이즈 방지
   - 센서 신호 필터링
   - 접지 설계 최적화

3. **열 관리**
   - 전력 소모 부품의 열 방출 설계
   - 온도 센서 정확도 보장

### 안전성 및 신뢰성
1. **EMC 대응**
   - 전자파 간섭 방지
   - ESD 보호 회로

2. **환경 대응**
   - 온도 범위: -10°C ~ 50°C
   - 습도 범위: 10% ~ 90% RH
   - IP54 이상의 방수/방진 등급
