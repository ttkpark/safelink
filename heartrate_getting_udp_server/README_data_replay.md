# UDP 서버 데이터 저장 및 재전송 시스템

## 📁 파일 구조

저장된 데이터는 다음과 같은 구조로 저장됩니다:

```
saved_data/
├── 2024/
│   ├── 01/
│   │   ├── 15/
│   │   │   ├── 14/
│   │   │   │   ├── 30/
│   │   │   │   │   ├── 2024_01_15_14_30_45.txt  # 2024년 1월 15일 14시 30분 45초
│   │   │   │   │   ├── 2024_01_15_14_30_46.txt  # 2024년 1월 15일 14시 30분 46초
│   │   │   │   │   └── 2024_01_15_14_30_47.txt  # 2024년 1월 15일 14시 30분 47초
│   │   │   │   └── 31/
│   │   │   └── 15/
│   │   └── 16/
│   └── 02/
└── 2025/
```

## 🚀 UDP 서버 실행

```bash
python udp_server.py
```

- 1000바이트 이상의 패킷이 수신되면 자동으로 시간별 파일에 저장됩니다
- 파일명 형식: `년_월_일_시_분_초.txt` (예: `2024_01_15_14_30_45.txt`)

## 📤 데이터 재전송

### 1. 사용 가능한 데이터 목록 보기

```bash
python test_client.py --list
```

### 2. 특정 시간의 데이터 재전송

```bash
python test_client.py --time 20240115143045
```

- 형식: `YYYYMMDDHHMMSS` 또는 파일명
- 예: `20240115143045` = 2024년 1월 15일 14시 30분 45초
- 파일명도 지원: `2024_01_15_14_30_45.txt` → 자동으로 `20240115143045`로 변환

### 3. 일반 시뮬레이션 모드

```bash
python test_client.py
```

## 🔚 연결 종료

### 서버에서 연결 종료 처리
- 클라이언트가 "end" 메시지를 보내면 서버에서 자동으로 연결 해제
- "disconnected" 응답을 클라이언트에 전송

### Processing에서 연결 종료
- **E 키**: 연결 종료 요청 전송
- 서버에서 "disconnected" 메시지를 받으면 자동으로 연결 상태 업데이트

## 💡 사용 예시

1. **서버 시작**:
   ```bash
   python udp_server.py
   ```

2. **데이터 수신 및 저장**: 1000바이트 이상 패킷이 자동으로 저장됨

3. **저장된 데이터 목록 확인**:
   ```bash
   python test_client.py --list
   ```

4. **특정 시간 데이터 재전송**:
   ```bash
   python test_client.py --time 20240115143045
   # 또는 파일명으로
   python test_client.py --time 2024_01_15_14_30_45.txt
   ```

5. **연결 종료**:
   - Processing에서 **E 키** 누르기
   - 또는 Ctrl+C로 클라이언트 종료

## ⚠️ 주의사항

- 1000바이트 미만의 패킷은 저장되지 않습니다
- 파일은 UTF-8 인코딩으로 저장됩니다
- 디렉토리는 자동으로 생성됩니다
- 같은 초에 여러 패킷이 오면 같은 파일에 추가됩니다
